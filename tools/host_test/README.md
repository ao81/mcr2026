# PC 上での動作比較テスト

実機がなくても、プログラムを書き換えたときに「走行の動きが変わっていないか」を PC で確かめるための道具です。
Arduino IDE では使いません（`basic/` フォルダの外に置いてあるので、書き込むプログラムには入りません）。

## 何をしているか

1. `mock/` にあるハードウェアの代わり（センサ、スイッチ、PWM、microSD）を使って、スケッチを PC 用にビルドします。
2. センサ値とスイッチの入力を乱数で作り、1ms ごとに割り込み処理と `loop()` を呼びます。
3. 1ms ごとに「pattern、サーボの PWM 値、左右モータの PWM 値と回転方向、LED」を1行ずつ出力し、最後に microSD に書かれたファイルの中身を出力します。
4. 元のプログラム（`reference/basic_original.ino`）と `basic/` の新しいプログラムで、この出力が1文字でも違えば「不一致」と表示します。

同じ seed（乱数の種）なら毎回同じ入力になります。入力は今の pattern に合わせて、その状態で意味のあるセンサ値を選びやすくしてあります。そのため、レーンチェンジの外側へふくらんだ時の処理（440〜450 など）まで通ります。

## 使い方（Linux / macOS / Windows の WSL）

```sh
tools/host_test/compare.sh 3000   # 3000通りの入力で比較する
```

`g++` が必要です。最後に「不一致: 0」と出れば、試した入力ではすべて同じ動きです。

## 注意

- 比較しているのは「元のプログラムと同じ動きをするか」だけです。速く走れるかどうかは実機で確かめる必要があります。
