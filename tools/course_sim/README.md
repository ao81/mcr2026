# コースの模擬（course_sim）

`basic/` の走行プログラムを PC 用にビルドし、計算で作ったコースと車の上で走らせる道具です。
新しい走行アルゴリズム（`config.h` の `USE_NEW_*`）が計算どおりに動くか、元のプログラムと比べて速いか、車の値がずれたときに失敗しないかを、実機の前に確かめるために使います。
Arduino IDE では使いません（`basic/` フォルダの外にあるので、書き込むプログラムには入りません）。

> この模擬は実機の代わりにはなりません。タイヤやモータの動きを簡単な式で置き換えているので、実機では違う結果になることがあります。分かるのは「計算の考え方が合っているか」と「どの値がずれると失敗しやすいか」です。

---

## 1. 使い方

`g++` が必要です（Linux、macOS、Windows の WSL）。

```sh
tools/course_sim/run.sh off                     # 元のプログラム（スイッチすべて 0）で6つのコースを走らせる
tools/course_sim/run.sh all crank_l lane_r      # スイッチすべて 1 で、左クランクと右レーンチェンジだけ
tools/course_sim/run.sh all lane_r avg=1        # スタートの位置を7通りに変えて、平均と失敗の回数を出す
tools/course_sim/compare.sh                     # 元と新しい方法をまとめて比べる（20秒ほど）
```

### 1-1. run.sh の引数

```
tools/course_sim/run.sh <スイッチ> [コース名 ...] [名前=値 ...]
```

| 引数 | 内容 |
|---|---|
| `<スイッチ>` | `config.h` の書き換えをカンマで区切って並べます。書き換えるのはコピーで、`basic/config.h` 自体は変わりません。<br>`off`：`USE_NEW_*` をすべて 0<br>`all`：`USE_NEW_*` をすべて 1<br>`名前=値`：その `#define` の値を書き換える<br>例：`all,CROSS_TO_CRANK_M=1.0f,PLAN_GRIP_RATIO_LAT=1.0f` |
| コース名 | `crank_l` `crank_r` `lane_l` `lane_r` `curve_l` `curve_r`。省略すると6つすべて |
| `名前=値` | 模擬の車とコースの「本当の値」（下の表）。プログラム側の `config.h` の値はそのままなので、「設定と本当の値がずれていた場合」を試せます |
| `avg=1` | スタートから特別な線までの距離を 1.400〜1.500m の7通りに変えて走らせ、平均の時間・失敗の回数・横Gの最大を1行で出します |

`avg=1` を使う理由：ラインの通過時間は 1ms 単位で数えるので、車がラインに来る時刻が少しずれるだけで、測った速さが 7〜8% 変わります。1回だけの結果は、その偶然で良くも悪くも見えます。比べるときは `avg=1` を付けてください。

### 1-2. 車とコースの本当の値（`名前=値`）

何も指定しないと、`config.h` に書いた値と同じになります（車の値が設定どおりの場合）。

| 名前 | 初期値 | 内容 |
|---|---|---|
| `v_max` | `V_MAX_MPS` | 出力100%で走り続けたときの速さ [m/s] |
| `tau` | `MOTOR_TAU_S` | 速さが変わるときの時定数 [s] |
| `grip_lat` | `GRIP_LAT_MPS2` | 横のグリップ [m/s²] |
| `grip_long` | `GRIP_LONG_MPS2` | 前後のグリップ [m/s²] |
| `servo_dps` | `SERVO_SPEED_DPS` | サーボが角度を変える速さ [度/s] |
| `servo_dead` | `SERVO_DEAD_S` | 指令からサーボが動き始めるまでの遅れ [s] |
| `sensor_to_axle` | `SENSOR_TO_REAR_AXLE_M` | 後輪の軸からセンサまで [m] |
| `half_w` / `front` | `CAR_HALF_WIDTH_M` / `CAR_FRONT_M` | コースアウトを判定する車体の角の位置 [m] |
| `line_w` | `0.032` | クロスライン・ハーフラインの白い部分の幅 [m] |
| `spot` | `0.004` | センサが白線の端からこの距離の内側なら白と判定する [m]。線は `line_w + 2 × spot` の幅に見える |
| `cross_to` | `CROSS_TO_CRANK_M` | クロスラインの終わりからクランクの曲がり角まで [m] |
| `half_to` | `HALF_TO_LANE_M` | ハーフラインの終わりから中央線が切れる所まで [m] |
| `lane_sec` | `LANE_SECTION_M` | 中央線が切れてから、新しい車線だけになるまで [m] |
| `lane_new` | `0` | 中央線が切れた所から、新しい車線の線が始まるまで [m] |
| `curve_r` | `0.45` | カーブのコースの半径 [m] |
| `approach` | `1.5` | スタートから特別な線（カーブのコースではカーブの入口）まで [m] |
| `dip` | `3` | DIPスイッチの値（3 = 出力100%） |
| `ms` | `6000` | 模擬する時間の上限 [ms] |
| `trace` | `0` | `1` にすると 10ms ごとの状態を表示する（下の 3 を参照） |

例：「本当の横のグリップが設定より 10% 低かったら」

```sh
tools/course_sim/run.sh all,CROSS_TO_CRANK_M=1.0f crank_l cross_to=1.0 grip_lat=7.2 avg=1
```

`CROSS_TO_CRANK_M`（プログラムが思っている距離）と `cross_to`（模擬のコースの距離）は、普通は同じ値にします。

## 2. 結果の見方

1回だけ走らせたとき：

```
crank_l  ゴール  1803 ms  最高 2.96 m/s  曲がり始め p=112 1.28 m/s  横G 100%  横すべり 0 ms  pattern: 100 101 102 103 112
```

| 項目 | 内容 |
|---|---|
| ゴール / コースアウト | スタート（pattern 20 になった時）からの時間。コースアウトは、車体の4つの角のどれかがコースの外に出た時刻 |
| 最高 | 一番速かった速さ |
| 曲がり始め | クランク・レーンチェンジで曲がり始めた pattern と、その時の本当の速さ |
| 横G | ハンドルの指令どおりに曲がるのに必要な横の加速度の最大を、本当の横のグリップに対する % で表したもの。100% を超えた分は曲がりきれず、外へふくらむ |
| 横すべり | 横と前後を合わせてグリップが 2% 以上足りなかった時間の合計 |
| pattern | 通った pattern 番号（100 以上だけ）。112/152 はクランクの円弧、360/660 はレーンチェンジのS字、380/680 はS字の後 |

`avg=1` のとき：

```
crank_l  平均  1785 ms  失敗 0/7  横G 最大  99%
```

平均はゴールできた回だけの平均です。

## 3. 1msごとの動きを見る（trace=1）

```sh
tools/course_sim/run.sh all lane_r trace=1 | less
```

10ms ごとに1行出ます。

| 項目 | 内容 |
|---|---|
| `t` | スタートからの時間 [ms] |
| `p` | pattern |
| `s` | センサの値（16進数。`18` は中央の2つが白） |
| `x` `y` `psi` | 後輪の軸の中心の位置 [m] と向き [度]。スタート時は `y` の向き（90度）に進む。右が `x` のプラス |
| `v` | 本当の速さ [m/s] |
| `steer` / `cmd` | サーボの本当の角度 / プログラムの指令 [度] |
| `pl` `pr` | 左右のモータ出力 [%] |
| `est` / `dist` | プログラムが推定した速さ [m/s] / ラインの終わりからの距離 [m] |
| `plan(...)` | プログラムが計算した経路（待つ距離、円弧の長さ、速さ、ハンドル角度） |

`v` と `est` の差が、速さの推定の誤差です。コースアウトした時は、外に出た角の位置も出ます。

## 4. 模擬の中身

### 4-1. コース

| コース | 形 |
|---|---|
| `crank_l` / `crank_r` | 直線 → クロスライン → `cross_to` 先で 90° の曲がり角 → 1m 進んだらゴール。コースの幅は 0.30m |
| `lane_l` / `lane_r` | 直線 → 変える側だけのハーフライン → `half_to` 先で中央線が切れる → 長さ `lane_sec` の区間は両方の車線を合わせた幅 → その先は新しい車線だけ。2m 進んだらゴール |
| `curve_l` / `curve_r` | 直線 → 半径 `curve_r` の 180° のカーブ → 戻りの直線を 0.3m まで戻ったらゴール |

### 4-2. 車の動き（1ms ごと、後輪の軸の中心で計算）

- **速さ**：`dv/dt = (左右の出力の平均/100 × v_max − v) ÷ tau`。タイヤが出せる前後の加速度は `grip_long` まで。
- **曲がり方**：曲率 = tan(サーボの角度) ÷ ホイールベース。
- **摩擦円**：横の加速度 `v² × 曲率` と前後の加速度が `(横/grip_lat)² + (前後/grip_long)² ≦ 1` を超えるときは、両方を同じ割合で縮めます。曲がりながらブレーキをかけると、曲がりきれずにふくらみ、ブレーキも弱くなります。
- **サーボ**：指令は `servo_dead` だけ遅れて届き、`servo_dps` の速さで角度が変わります。
- **センサ**：後輪の軸から `sensor_to_axle` 前、`SENSOR_X_MM` の8か所。白線（端から `spot` の内側を含む）の上なら白。
- **コースアウト**：後輪の位置と、そこから `front` 前の位置の、それぞれ左右 `half_w` の4点のどれかがコースの外に出たら失敗。

### 4-3. 入っていないもの

- タイヤが限界を超えた後にグリップが下がること（実際のタイヤは、すべり始めると出せる力が少し下がります）
- 車の向きが回りすぎる動き（スピン）、車体の傾き、坂
- 電池の電圧が走行中に下がること（`v_max` は一定）
- センサの読み取りのばらつき、白線の汚れ

模擬では、横Gが 100% を少し超えても、ふくらむだけで済むことがあります。元のプログラムがカーブで模擬上は速いのはこのためで、実機でも同じとは限りません。

## 5. 今の結果（2026年11月、`config.h` の初期値、車の値は設定どおり）

`tools/course_sim/compare.sh` の結果です。どれも7通りのスタート位置の平均です。

| コース | 元のプログラム | クランク・レーンチェンジだけ新しく | すべて新しく |
|---|---|---|---|
| クランク（クロスラインから 0.5m） | 7回とも失敗 | 1577 ms | 1587 ms |
| クランク（1.0m） | 7回とも失敗 | 1796 ms | 1785 ms |
| レーンチェンジ（ハーフラインから 0.5m） | 1732 ms | 1666 ms | 1673 ms |
| レーンチェンジ（1.0m） | 1912 ms | 1836 ms | 1840 ms |
| カーブ 半径 0.8m | 7回とも失敗 | ― | 2272 ms |
| カーブ 半径 1.0m | 2256 ms | ― | 2346 ms |
| カーブ 半径 1.5m | 2777 ms | ― | 2788 ms |

- 模擬の車は `config.h` の初期値（`V_MAX_MPS` 3.0 m/s、横のグリップ 8.0 m/s² など）なので、元のプログラムが調整された実機とは違います。元のプログラムのクランクが失敗するのは、この車では進入が速すぎる（1.0m で 2.2 m/s）ためです。
- クロスラインから 0.5m では、3m/s から計算の速さ（約 1.2 m/s）まで落とすのに距離が足りません。新しい方法は円弧をあきらめ、元の曲がり方で曲がっています（`docs/tuning_guide.md` の 2-7「元の方法に戻る条件」）。
- カーブは、元のプログラムの方が半径 1.0m で 90ms 速く、半径 0.8m では元のプログラムだけが失敗しました。新しい方法はグリップの 90% までしか使わないので、少し遅くなります。

| ずらした値 | クランク | レーンチェンジ |
|---|---|---|
| `v_max` −10% 〜 +10% | 失敗 0 | 失敗 0 |
| `tau` −30% 〜 +30% | 失敗 0 | 失敗 0 |
| `grip_lat` −10% | 失敗 0 | 失敗 0 |
| `grip_lat` −20% | 失敗 0 | 7回とも失敗 |
| `grip_long` −10% | 失敗 0 | 失敗 0 |
| `grip_long` −20% | 6回失敗 | 失敗 0 |
| `servo_dps` 400（2/3）、`servo_dead` 0.02 | 失敗 0 | 失敗 0 |
| `sensor_to_axle` ±15mm | 失敗 0 | 失敗 0 |
| `line_w` 0.028 〜 0.034（見える幅 −10% 〜 +5%） | 失敗 0 | 失敗 0 |
| `line_w` 0.036（見える幅 +10%） | 2回失敗 | 2回失敗 |
