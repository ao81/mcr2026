マイコンカー パラメータ編集

basic/config.h（調整用パラメータ）と debug/dbg_config.h（デバッグモードの設定）を読み込んで編集します。

Braveで直接同期する場合はリポジトリで python tools/config_editor.py を実行し、表示されたURLを開いてください。
「保存」すると basic/config.h を書き換え、debug/config.h にも同じ内容をコピーします（debug/sync.sh と同じ）。
