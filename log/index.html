デバッグモードの CSV（CRK0001.csv・LANE0001.csv・CURV0001.csv・TRCE・FULL・dbg0001.csv）を開くと、区間の要点の表とグラフを出します。 ファイルはこのブラウザの中だけで読み、どこにも送りません。3本まで重ねて比べられます（区間に入った時を 0 ms にそろえます）。 パラメータ編集・道具の一覧

要点

時間は区間に入った時（クロスライン・ハーフラインを見つけた時、カーブなら曲がり始めた時）からの ms です。 「1ms 単位」は、その前の行が 1ms 前にあるので時刻がちょうど分かる値です。「〜N ms」は前の行から N ms あいているので、その間のどこかで起きた値です。 距離はラインの終わり（曲がり角の線を見つけた後は、その所）からの推定の距離です。

グラフ

グラフの上でドラッグすると、その範囲を拡大します。線の上に指やマウスを置くと値を出します。
